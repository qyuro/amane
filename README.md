### my amane-conf ###

`library-build.rs` — локальная правка библиотеки amane для экрана блокировки:
поверхности создаются сразу после `lock()`, не дожидаясь `locked()`. Без неё
niri ждёт до секунды и показывает свой красный фон. Скрипт запуска копирует
этот файл в `~/.cache/amane/library/build.rs` перед `amane compile`.

## Бар

- Иконка картинки открывает выбор обоев из `~/Wall`. Превью лежат в
  `~/.cache/amane/wallpapers` и делаются в фоне через `magick`; клик по
  картинке сразу ставит обои через `awww` и пересобирает палитру.
- Иконка динамика открывает панель громкости. Колесо над иконкой тоже
  меняет уровень, а при смене громкости хоткеем niri появляется полоса
  на всю ширину раскрытого бара с процентом.
